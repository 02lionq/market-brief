# 미국장 브리핑

전날 미국 증시 마감을 한 장으로 정리해 매일 아침 만들어 주는 도구.
데이터는 야후파이낸스(yfinance)에서 가져오며 **API 키 없이** 동작한다.
AI 요약과 뉴스 번역만 선택적으로 Gemini 키를 쓴다.

## 브리핑에 담기는 것

| 구분 | 내용 |
| --- | --- |
| 핵심 요약 | 어제 시장이 왜 그렇게 움직였는지 3줄 (AI, 선택) |
| 지수 | S&P 500 · 나스닥 · 다우 · 러셀 2000 |
| 지금 | S&P·나스닥·다우 선물과 비트코인의 실시간 값 |
| 경제 캘린더 | FOMC · CPI · 고용보고서 등 앞으로 30일 일정 |
| 1년 추이 | 지수 4종을 같은 축에서 비교한 차트 |
| 기간별 성과 | 1주 · 1개월 · 3개월 · 6개월 · 연초 대비 |
| 시장 폭 | 시총가중(SPY)과 동일가중(RSP) 비교 |
| 금리 | 3개월 · 5년 · 10년 · 30년 + 장단기 금리차 |
| 원자재 | WTI · 금 · 은 · 구리 · 천연가스 |
| 환율 | 원/달러 · 원/엔 · 원/유로 · 달러/엔 · 유로/달러 · 달러인덱스 |
| 해외 지수 | 코스피 · 코스닥 · 니케이 · 항셍 · 상해 · 유로스톡스 · DAX · FTSE |
| 섹터 | 미국 11개 업종 |
| 특징주 | 대형주 40개 중 등락 상위·하위 5종목 |
| 관심종목 | 등락률 · 원화 기준 등락 · 52주 위치 · 실적 발표일 |
| 뉴스 | 시장 뉴스와 내 종목 뉴스 (한글 번역 + 원문 병기) |

## 데이터 출처

- **시세·실적일** — 야후파이낸스 (yfinance, 키 불필요)
- **경제 일정** — 미국 정부 공식 소스
  - 노동통계국(BLS) 공식 ICS 캘린더 — CPI · 고용보고서 · PPI
  - 연방준비제도 — FOMC 회의 일정
  - 경제분석국(BEA) — GDP · PCE
- **AI 요약·번역** — Google Gemini (선택)

민간 금융 사이트 대신 정부 원본을 쓴다. 구조가 잘 바뀌지 않고 봇 차단이 없다.

## 내 PC 에서 쓰기

```
run.bat                 브리핑을 새로 만들고 브라우저로 연다
관심종목 편집.bat        관심종목을 창에서 추가·삭제한다
```

설정은 `config.py`, 관심종목은 `watchlist.json`, API 키는 `.env` 에 둔다.
뒤의 두 파일은 **깃허브에 올라가지 않는다** — 저장소를 공개해도 내 종목과
키는 드러나지 않는다. 형식은 `watchlist.example.json` 과 `.env.example` 참고.

## 깃허브에서 자동으로 돌리기

`.github/workflows/daily-brief.yml` 이 **매주 화~토 한국시각 오전 7시 30분**에
브리핑을 만들어 `docs/` 폴더에 저장한다. 저장소 설정에서 GitHub Pages 를
`main` 브랜치의 `/docs` 폴더로 지정하면 웹 주소로 볼 수 있다.

AI 요약을 쓰려면 저장소 **Settings → Secrets and variables → Actions** 에
`GEMINI_API_KEY` 를 등록한다. 없어도 나머지는 정상 동작한다.

깃허브 서버에는 `watchlist.json` 이 없으므로, 공개되는 브리핑에는
**관심종목 표와 내 종목 뉴스가 빠진다.** 지수·환율·경제일정 같은
공개 정보만 올라간다.

## 파일 구성

```
brief.py              본체 — 수집 · 계산 · HTML 생성
config.py             설정 (뉴스, 색상, 캘린더)
econ_calendar.py      경제지표 일정 수집
watchlist_editor.py   관심종목 편집 창
watchlist.json        내 관심종목      (깃에 올라가지 않음)
.env                  API 키           (깃에 올라가지 않음)
docs/                 깃허브가 만든 브리핑 (웹 공개)
output/               내 PC 에서 만든 브리핑
history.csv           지수·지표 1년치 기록
```

## 알아둘 점

- 미국장이 **진행 중**일 때 실행하면 그날은 빼고 직전 마감일을 기준으로 잡는다.
  개장 몇 분치 값을 "종가"라고 부르지 않기 위해서다.
- 비트코인은 24시간 거래되므로 주말 값이 생긴다. 기록 파일에는 미국장이
  열린 날만 남긴다.
- 화면의 카드와 종목 이름을 누르면 야후파이낸스 원본으로 이동한다.
